# DonUp 도움말 콘텐츠 운영

2026-10-29 기준. 실제 검색어 보고서가 아직 처리 중이므로 수요·검색량·인용 수치를 만들지 않는다.

## 원장과 발행 규칙

- 콘텐츠 원장: support-content.json과 i18n/support-*.json. 5개 언어, 언어별 FAQ 34개. question은 대상 질문, answer는 첫 직답, facts는 조건, steps는 실제 앱 순서다.
- 2026-10-29 갱신: import(파일 형식·13MB·무료 범위·암호·저장 주의·5단계), automation(Pro·로그인·AI 동의·iOS 27 조건). updated는 내용이 실제 바뀔 때만 고친다.
- 근거: 앱 LedgerExternalImportSupport.swift:12–14,248–268,562–676, LedgerExternalImportOnboardingSheet.swift:183, LedgerSettingsPage.swift:676–688,1069–1070,1650–1655,4558–4576. Office 암호 처리: supabase/functions/import-ledger-data/index.ts:1270–1340. 근거는 내부 검토용이며 배포되지 않는다.
- 저장 전 검토: 금액·날짜·통화 확인, 개인 데이터 대체 경고, 공유 가계부 유지 여부를 원문과 대조한다. 경쟁 앱별 호환을 보장하지 않는다.
- HTML과 FAQ JSON-LD, RSS는 이 원장에서 생성한다. 숨겨진 SEO 전용 답을 쓰지 않는다. /feed.xml과 언어별 feed.xml은 갱신일 있는 공식 도움말만 제공한다.
- content/page-dates.json은 실제 편집일이다. 법적 문서처럼 갱신일 근거가 없는 경로에는 lastmod를 임의로 채우지 않는다.
- npm test → 모바일·데스크톱 화면 검토 → npm run deploy. 배포 후 IndexNow가 공개 키와 실제 운영 HTML의 소스 리비전을 확인하고 변경 URL만 제출한다. 접수 성공을 색인 성공으로 부르지 않는다.
- IndexNow 접수 이력: 로컬 .cache/indexnow.json(미추적). 같은 작업 폴더의 반복 배포는 변경 없는 URL을 다시 보내지 않는다. 다른 PC나 초기화된 캐시에서는 최초 전체 제출한다.
